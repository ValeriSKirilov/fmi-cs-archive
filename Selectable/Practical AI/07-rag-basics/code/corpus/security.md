# Политика за сигурност и достъпи

Всички служебни акаунти изискват двуфакторна автентикация (2FA). Паролите се пазят
само в одобрения password manager, никога в текстови файлове или чатове.

API ключове и токени не се качват в git. Използвайте `.env` файлове (в `.gitignore`)
или централния secrets manager. Изтекъл ключ се ротира незабавно и се докладва на
security екипа.

Достъп до production бази данни се дава само след одобрена заявка и е с изтичащ срок.
Служебните лаптопи са с криптиран диск и автоматично заключване след 10 минути.
