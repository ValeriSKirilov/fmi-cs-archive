Числа на Фибоначи
Дадена е редицата от числа на Фибоначи, дефинирана по следния начин:
А[0] = 1, A[1] = 1
A[n] = A[n-1] + A[n-2], n >= 2
Намерете n-ия член на редицата.
     
Вход
Първият ред съдържа едно цяло число - n (0 <= n <= 45)

Изход
Отпечатайте A[n]. 

Пример
Вход
4
Изход
5

Обяснение на примера
A[0] = 1
A[1] = 1
A[2] = A[1] + A[0] = 1 + 1 = 2
A[3] = A[2] + A[1] = 2 + 1 = 3
A[4] = A[3] + A[2] = 3 + 2 = 5
