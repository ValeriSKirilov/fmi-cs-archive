# Упражнение 2 — код

Практическа част към Лекция 2: промптът като **шаблон**, **параметрите** за
семплиране като конфигурация и **управление на контекста** на ръка. Надгражда
мини-чата от Упражнение 1.

## Преди упражнението (направете го вкъщи)

```bash
# 1. Виртуална среда (от папката lectures/02-system-design/code)
python3 -m venv .venv && source .venv/bin/activate
#    Windows:  .venv\Scripts\activate

# 2. Зависимости
pip install -r requirements.txt

# 3. Настройки (ключ НЕ е нужен — по подразбиране всичко е локално)
cp .env.example .env

# 4. Локалният модел от Упражнение 1 — ако вече го имате, пропуснете
ollama pull hf.co/INSAIT-Institute/BgGPT-Gemma-3-4B-IT-GGUF:Q4_K_M
ollama cp   hf.co/INSAIT-Institute/BgGPT-Gemma-3-4B-IT-GGUF:Q4_K_M bggpt:4b
```

**Ubuntu/Debian:** ако стъпка 1 гръмне с `ensurepip is not available`, липсва
системният пакет — `sudo apt install python3-venv` и повторете. Без sudo:
`uv venv .venv && uv pip install -r requirements.txt` ([uv](https://docs.astral.sh/uv/)).

Проверка на средата — едно извикване, ~5 s:

```bash
python llm.py          # -> [ok] Средата е готова за упражнението.
```

**Колко е бавно?** Локалният модел върви на процесора: един отговор е 4–40 s
според дължината. Задача 3 (6 реплики + резюме) отнема ~2.5 мин на режим.

**За пускане с определен модел:** всеки скрипт приема `--model`, напр. `--model llama3.2:1b` (по-бърз, но слаб
на български — видяхме го в Упражнение 1). Бонус eval-ът го хваща: 8/8
*валидни* етикета, но само 3/8 *верни* — казва „отрицателно“ на всичко.
**Имате Anthropic ключ?** Всеки скрипт приема и `--provider anthropic`.

## `llm.py`

Споделен модул, който **не редактирате**. Дава една функция `chat(...)`, която
всички задачи ползват, без да знаят кой доставчик отговаря. Това е малката
версия на адаптера от Упражнение 1: разликите между Ollama и Anthropic (къде
отива `system`, как се казва таванът на изхода, кой модел приема `temperature`)
живеят на едно място. Прегледайте го — за да знаете какво ви е спестено.

## `demo_temperature.py` (демонстрация)

`client.messages.create(..., temperature=0)` днес се чупи по два начина:
SDK 1.x махна аргумента (`TypeError`), а най-новите модели отказват полето
(`HTTP 400`). По-старите го приемат през `extra_body`. Ако искате да го
пробвате сами: `python demo_temperature.py` (изисква `ANTHROPIC_API_KEY`). Изводът: знанието „кой модел какво
приема“ остарява, затова е на **едно** място (`ANTHROPIC_SAMPLING` в `llm.py`).

## Бележки

- `temperature=0` не гарантира бит-в-бит еднакъв изход: първото извикване след
  друг промпт понякога се различава (кешът на промпта). Същото важи за `--seed`.
- Прагът за свиване в `03_memory.py` е по брой съобщения (`MAX_MESSAGES`); в
  реален продукт е по-точно да е по преброени токени.
- Готови абстракции за същите неща идват по-късно: Vercel AI SDK (Лекция 4),
  паметта на LangGraph (Лекция 12). Първо „под капака“, после библиотека.
